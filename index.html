[ 01 ] ¿Qué es una Skill?

Conocimiento procedimental, no código suelto.

Una Skill es un paquete reutilizable que extiende lo que un agente puede hacer. No la ejecuta el modelo: la lee y la sigue. Aporta tres cosas.

/ 01

Instrucciones

Protocolos explícitos de cómo abordar una tarea concreta, paso a paso y con criterios de término.

/ 02

Buenas prácticas

Convenciones, checklists y estándares del dominio que garantizan rigor y consistencia.

/ 03

Recursos

Scripts y esquemas auxiliares que el agente ejecuta o consulta bajo demanda, como scripts/.

[ 02 ] Anatomía

Formato abierto: SKILL.md

Estándar adoptado por Google Antigravity y el agente de la Gemini API. Una carpeta, un manifiesto y recursos opcionales.

auditor-tecnico-proyectos/
├── SKILL.md          # requerido
├── scripts/          # código determinista
├── references/       # rúbricas
└── assets/           # plantillas

El frontmatter YAML define el name y la description: la descripción es el mecanismo de disparo, declara qué hace la Skill y cuándo debe usarse.

El runtime escanea .agents/skills/ en el workspace y ~/.gemini/config/skills/ de forma global; las Skills se autodescubren.

[ 03 ] Ciclo de vida

Divulgación progresiva

El agente no carga todo siempre: descubre, activa solo lo relevante y ejecuta.

Descubrimiento

Al iniciar, el agente ve la lista de Skills con su nombre y descripción.

Activación

Si la descripción encaja con la tarea, lee el SKILL.md completo.

Ejecución

Sigue las instrucciones mientras trabaja. Invocación autónoma o manual.

[ 04 ] La Skill

auditor-tecnico-proyectos

Un flujo de tres pasos con criterios de término verificables. Primero medir, después juzgar.

  • Paso 1
    Inventaría con evidenciaEjecuta el escáner determinista: cuenta archivos y líneas por lenguaje, detecta manifiestos y señales objetivas de riesgo. Nunca opina sin datos.
  • Paso 2
    Evalúa cada dimensiónRecorre una rúbrica de 8 dimensiones —estructura, dependencias, seguridad, escalabilidad, calidad, observabilidad, documentación y mantenibilidad— anclando cada nota a un hecho.
  • Paso 3
    Emite el informeAplica una plantilla fija: resumen ejecutivo, hallazgos por severidad y un plan priorizado por impacto × esfuerzo.
