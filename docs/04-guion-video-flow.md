## Prompt / indicaciones para Flow

```
Genera un video corto vertical (9:16) de ~55 segundos, estilo tecnológico
moderno, sobre "Skills integrados a Gemini" para ingeniería de sistemas.

1. Ingeniero frente a terminal con código.

4. Flujo: código → inventario → rúbrica → informe.
5. Informe con hallazgos por severidad.
6. Cierre con logo y URL de GitHub.
Usa texto en pantalla breve en español, ritmo dinámico y música corporativa suave.
```
